Security notes
--------------
- Keep Hostinger Firewall rules for 22/1433/3306 restricted to approved /32 public IPs.
- Never paste passwords into tickets, chat, source files or this example file.
- Use wf_reader for routine inspection and reporting.
- Use wf_owner, sa and MySQL root only for approved maintenance.
